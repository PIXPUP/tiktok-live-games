# คลังของขวัญ TikTok LIVE

เก็บรายการจากแค็ตตาล็อกสาธารณะ 1,851 รายการ และรูป WebP ไม่ซ้ำกัน 1,833 ไฟล์ โหลดสำเร็จทั้งหมดใน snapshot นี้

- catalog.json: ชื่อ, ID ที่ตรวจสอบได้, เหรียญ, ไฟล์รูป, URL ต้นทาง และชื่อเรียกเพิ่มเติม
- icons/: รูปที่เก็บไว้ในเครื่อง ไม่ต้องดึง TikTok CDN ตอนเปิดหน้าจอไลฟ์
- download-report.json: จำนวนที่พบ ดาวน์โหลดสำเร็จ และรายการที่ล้มเหลว
- SOURCES.md: แหล่งข้อมูลและการระบุเจ้าของภาพ

ID เป็น null สำหรับรายการที่ยังยืนยัน ID ไม่ได้ โปรแกรมใช้ชื่อของขวัญตรงตัวในการจับคู่แทน ไม่สร้าง ID ขึ้นเอง ของขวัญเฉพาะประเทศ ห้องไลฟ์ และเทศกาลอาจต่างจากรายการนี้ รายการเก่าบางชิ้นอาจไม่เปิดให้ส่งแล้ว

ภาพเป็นของ TikTok และผู้ถือสิทธิ์ ใช้เพื่อระบุของขวัญ ไม่ใช่ภาพที่สร้างใหม่หรือโอนสิทธิ์ให้ผู้ดาวน์โหลด
