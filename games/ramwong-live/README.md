# รำวงสามช่า LIVE

เกมที่ 5 ของ Game Desk ฉากงานวัดยามเย็น มีนักเต้นชาย/หญิง ชื่อผู้ส่งจริง และท่าเต้นแปดแบบ ของขวัญ Hand Heart เพิ่มคู่รำ ส่วน Galaxy เปิดฟลอร์ใหญ่ เดโมทุก 5 วินาทียังเล่นพร้อมของขวัญจริงได้ ชื่อจริงมีลำดับก่อนเดโม

เปิดโปรแกรม → เลือกรำวงสามช่า → เปิดเกม → หน้าควบคุม → เปิดเพลงคลอ จากนั้นสร้างลิงก์ Cloudflare ไปใส่ Link Source 1080 × 1920 ใน LIVE Studio และจับเสียงระบบของ Windows ถ้าเปิดเพลงจากโปรแกรมแล้ว ให้เปิดเพลงเพียงแหล่งเดียวเพื่อไม่ให้เสียงซ้อน

ตัวเชื่อมปัจจุบันยังใช้ TikFinity Desktop และ Event API 21213 บนคอมเครื่องเดียวกัน เกมใหม่ไม่ได้เปลี่ยนการเชื่อม TikFinity หรือแก้การเชื่อมไลฟ์ที่ยังมีปัญหา

พอร์ตเกม 8805 / bridge 8806 / read-only gateway 8808 โหมดประหยัดแสดงสูงสุด 4 คนและลดท่าเคลื่อนตัวเสริม แต่คงภาพเปลี่ยนท่ารำ ไม่มีฉาก 3D หรือการประมวลผลเพลงสด

|---|---|

| Finger Heart | โยกซ้ายขวา |

ปรับ mapping ตามของขวัญที่บัญชีรับได้ใน gift-map.json ภาพไอคอนใช้ภาพเดิมในโปรเจกต์

เพลงสามช่าบรรเลงต้นฉบับ 120 BPM ยาว 32 วินาทีและวนซ้ำ สังเคราะห์จากโค้ด desktop/ramwong_music.py มีเบส คอร์ด ทำนอง และจังหวะเครื่องเคาะ ไม่ใช้ไฟล์บันทึกเสียงหรือทำนองจากเพลงของผู้อื่น ดู MUSIC.md ภาพฉากและตัวละครสร้างด้วย imagegen ดู ART_PROMPTS.md
