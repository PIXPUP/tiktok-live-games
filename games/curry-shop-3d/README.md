# หมูเฮง · ตามสั่ง LIVE 3D

เปิด `START.bat` (ต้องมี Node.js 22 ขึ้นไป) แล้ว Chrome เข้า http://127.0.0.1:8775/
เกมใหม่แยกจากลานบุญ ใช้พอร์ต 8775 และตัวรับของขวัญ 8776

ภาพ WebGL 3D ร้านข้าวราดแกง มองจากหน้าร้านลงมาเล็กน้อย แม่ค้าอยู่หลังเคาน์เตอร์ช่วงบน ถาดแกง 6 ถาด และลูกค้าต่อคิวช่วงล่าง

ผู้ส่งของขวัญจะสร้างตัวละครพร้อมชื่อ เดินเข้าคิว สั่งอาหาร แม่ค้าขยับตักแกง ตัวละครรับจานข้าวแล้วเดินออกด้านข้าง แสดงคิวจริง 6 คนพร้อมลูกค้าที่กำลังสั่ง 1 คน รายการที่เกินจะรอในคิวและทยอยแสดง ของขวัญซ้ำจากคนเดียวกันและเมนูเดียวกันขณะรอรวมจำนวนในออร์เดอร์เดียว ปุ่มทดลองไม่เพิ่มอันดับลูกค้าจริง

จอไลฟ์: http://127.0.0.1:8775/?overlay=1&v=3 ขนาด 1080×1920
เสียงแจ้งรับอาหารสร้างด้วย Web Audio ต้องกดเปิดเสียงร้านเอง

Three.js 0.170.0 อยู่ใน vendor พร้อมใบอนุญาต MIT เกมนี้ยังอยู่ในเครื่องและไม่บันทึกคิว/คะแนนข้ามการรีเฟรช ถ้าเปิดเกมลานบุญพร้อมกัน ทั้งสองเกมอาจตอบสนองต่อของขวัญเดียวกัน

รายละเอียดอาหารเวอร์ชัน 4: ถาดพะโล้มีไข่ผ่า หมูสามชั้นและโป๊ยกั๊ก เขียวหวานมีไก่ มะเขือ โหระพาและกะทิ กะเพรามีหมูสับกับพริก พริกแกงมีถั่วฝักยาว หมูทอดมีชั้นหนัง กระเทียมและงา ผัดผักรวมมีแครอตและผักเขียว จานอาหารเปลี่ยนตามเมนู มีข้าวเป็นเมล็ดและแตงกวา ใช้ InstancedMesh ลดจำนวนการวาดวัตถุดิบซ้ำ

เวอร์ชัน 5 ใช้ชื่อเมนูและรายการอาหารจากแค็ตตาล็อกเดียวกันทั้งป้ายถาด ปุ่ม ออร์เดอร์ และจาน เมนูเหมายกร้านรวมอาหารครบทั้ง 6 ถาด ส่วนผัดผักรวมอยู่ในชุดอิ่มอร่อยและเหมายกร้าน

เวอร์ชัน 7: โต๊ะกินข้าว 4 โต๊ะข้างทางเดิน ลูกค้าที่สั่งเมนูมีอาหารอย่างน้อย 2 ชนิด (ข้าวสองอย่าง ชุดอิ่มอร่อย เหมายกร้าน) รับจานแล้วเดินไปนั่ง 9 วินาที ลุกและเดินออก เก้าอี้จองเฉพาะลูกค้าคนนั้น โต๊ะเต็มรอโต๊ะว่าง เมนูอย่างเดียวรับกลับ แม้ส่งของขวัญชนิดเดียวหลายชิ้นก็ไม่นับเป็นอาหารสองอย่าง

เวอร์ชัน 8: เสียงประกอบสังเคราะห์ด้วย Web Audio ทั้งหมด ไม่มีไฟล์เสียงบันทึกหรือ sample ภายนอก ได้แก่ ฝีเท้า กระดิ่งออร์เดอร์ ตักอาหาร วางจาน รับอาหาร ขยับเก้าอี้ ชุดใหญ่ และเสียงครัวเบา ๆ เปิดจากปุ่มเสียงร้านหรือปุ่มในจอไลฟ์ ปรับความดังและทดลองฟังได้ ไม่ใช้ API หรือ token เสียงไม่เริ่มก่อนกดเปิด และจำกัดความถี่/จำนวนเสียงซ้อน

เวอร์ชัน 9: เปลี่ยนเสียงพื้นหลังจากเสียงครัวเป็นเพลงต้นฉบับ “เช้าวันสบาย ร้านหมูเฮง” แนว idle/casual 90 BPM วน 16 ห้อง เสียงคีย์นุ่ม เบส คอร์ดและเครื่องจังหวะคำนวณจากคลื่นเสียง ไม่ใช้เพลงหรือ sample ผู้อื่น ไม่ใช้ API ปรับความดังเพลงแยกจากเอฟเฟกต์ และปิดเฉพาะเพลงได้ เปิดเสียงร้านก่อนฟัง ปุ่มปิดเสียงร้านหยุดทุกเสียง

เวอร์ชัน 10: แม่ค้าขอบคุณและเรียกชื่อลูกค้าตอนส่งอาหาร หมุนเวียนบทพูด ทานให้อร่อยและชวนกลับมา เสียง speechSynthesis ภาษาไทยจากเบราว์เซอร์ เลือกเสียงและความดังได้ ไม่มี paid API เปิดเสียงร้านจะเปิดเสียงแม่ค้าด้วยเมื่อมีเสียงไทย ปิดเฉพาะแม่ค้าได้ ลดเพลงเหลือ 23% ระหว่างพูด คิวจำกัดและรวมคำขอบคุณเมื่อคิวยาว ไม่พูดทับกัน

เวอร์ชัน 11: เปลี่ยนภาชนะอาหาร 6 ถาดเป็นถาดหลุมสแตนเลส ขอบม้วนมน ผนังด้านในลาดลง ก้นถาดลึก ฝังในช่องเปิดจริงของหน้าเคาน์เตอร์ และลดระดับอาหารให้อยู่ภายในถาด
