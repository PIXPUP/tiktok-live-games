# ศาลาพระพิฆเนศ LIVE

เกมใหม่คัดลอกจากเกมลานบุญ แยกไฟล์ คะแนน เซิร์ฟเวอร์ และตัวเชื่อมของขวัญจากเกมเดิม

- เปิด START.bat เพื่อเปิดเกมและตัวเชื่อม TikFinity
- หน้าควบคุม http://127.0.0.1:8785/?v=9
- จอไลฟ์ http://127.0.0.1:8785/?overlay=1&v=9 ขนาด 1080 × 1920
- เปิด CLOUDFLARE_START.bat เพื่อออกลิงก์สาธารณะ อ่านลิงก์ล่าสุดจาก LIVE_URL.txt
- พอร์ตเกม 8785 ตัวเชื่อม 8786 gateway 8788; เกมลานบุญเดิมยังใช้ 8765/8766/8768
- เกมสองชุดมีคะแนนแยกกัน แต่หากเปิดตัวเชื่อมของขวัญพร้อมกัน ทั้งคู่จะตอบสนองต่อของขวัญเดียวกัน ให้เปิดตัวเชื่อมเฉพาะเกมที่ต้องการใช้ไลฟ์

| ของขวัญ | กิจกรรม |
|---|---|
| Rose | ถวายดอกไม้ |
| Finger Heart | ถวายขนมโมทกะ |
| Rosa | ถวายผลไม้ |
| Perfume | ถวายนม |
| Doughnut | จุดประทีป |
| Paper Crane | ถวายธูปหอม |
| Hand Heart | บูชาอารตี |
| Galaxy | มหาอารตี |

ตัวละครเคลื่อนที่และกราบบนพรมแดง รูปของขวัญใช้ชุดเดียวกับเกมเดิม พร้อมบทพูดผู้ดูแลศาลาและเพลงบรรเลงสร้างใหม่ เปิดเสียงด้วยปุ่มในหน้าควบคุมก่อนออกไลฟ์ ใช้ System Audio หากส่งเสียงจาก Chrome อย่าเปิดเสียงซ้ำหลายหน้าต่าง

เกมนี้ใช้บทสวด Ganesha Atharva Sheersha ของ Dr Arun Apte แทนเสียงสวดพุทธของเกมต้นฉบับ ดูเครดิตและสถานะสิทธิ์ใช้เสียงใน chant-audio/SOURCE.md ภาพประกอบเป็นภาพสร้างใหม่ด้วย imagegen ไม่ใช่สถานที่จริง ของถวายกับคะแนนเป็นกิจกรรมจำลอง ไม่ใช่การบริจาคเงินจริง ไม่อ้างว่าผู้ส่งของขวัญจะได้รับผลตอบแทนจากศาสนา

## เวอร์ชันล่าสุด

- ฉากศาลาพระพิฆเนศกลางแจ้ง แถบของขวัญสองข้าง ฝั่งละ 4 รายการ
- ตัวละคร 4 แบบ: เสื้อยืดเขียว เสื้อยืดชมพู เสื้อโปโลเหลือง และชุดขาว เลือกแบบคงที่จากชื่อผู้ชม พร้อมท่ากราบครบทุกแบบ
- บทพูดวนพระพิฆเนศที่กำหนดไว้ เลือกในรูปแบบเสียงพูดวนและกดเปิดพูดวน ของขวัญจะขัดจังหวะเพื่อกล่าวขอบคุณก่อน
- บทสวดวนมีปุ่มเปิด/ปิดและปรับความดัง ลดเสียงอัตโนมัติตอนพูด และเปิดสลับกับเพลงคลอ

ก่อนใช้ Cloudflare ในคอมใหม่ ให้รัน SETUP_CLOUDFLARE.bat จากโฟลเดอร์หลักของ repo เพื่อวาง cloudflared.exe ใน bin ของเกมนี้
