# ตักบาตรยามเช้า

เกมที่ 4 ของ TikTok LIVE Game Desk ฉากลานวัดกลางแจ้ง พระถือบาตรเดินผ่านและหยุดรับอาหารจากผู้ส่งของขวัญ ตัวละครผู้ชมเดินเข้ามาถวายอาหารแล้วไหว้ลา แสดงชื่อผู้ส่งจริงก่อนตัวละครเดโม

เปิดจากโปรแกรม Game Desk → เลือกตักบาตรยามเช้า → เปิดเกม → สร้างลิงก์ Cloudflare → คัดลอกไปใส่ Link Source ขนาด 1080 × 1920 ใน TikTok LIVE Studio

หน้าควบคุมมีเดโมทุก 5 วินาที ปุ่มเพลงคลอ ระดับเสียง และเสียงขอบคุณภาษาไทยออนไลน์ ของขวัญจริงต้องเปิด TikFinity Desktop และ Event API พอร์ต 21213 ให้เชื่อมบัญชีที่กำลังไลฟ์ เดโมทำงานพร้อมของขวัญจริงได้และไม่เพิ่มคะแนน

พอร์ตเกม 8795, bridge 8796, read-only gateway 8798 เปิดได้ครั้งละเกมจาก Game Desk โหมดประหยัด RAM ลดคนเหลือ 4 คนและลดเอฟเฟกต์ ไม่ได้รับประกันการไลฟ์บนเครื่อง RAM 2 GB

ชื่อและราคาของขวัญใน TikTok อาจต่างกันตามบัญชี ตั้งค่ารายการที่รับจริงได้ใน gift-map.json คะแนนเป็นกิจกรรมเสมือนในเกม

เพลงคลอสังเคราะห์จากโค้ดเดิม ส่วนเสียงทำวัตรเช้าใช้แหล่งเดิมของเกมลานบุญและยังไม่ได้ยืนยันสิทธิ์เผยแพร่เชิงพาณิชย์ จึงปิดไว้โดยค่าเริ่มต้น ดู THIRD_PARTY_NOTICES.md และ chant-audio/WATMARPJAN-SOURCE.md
