# Pages + Tunnel

เว็บรวม: https://pixpup-live-games.pages.dev

- เปิดเว็บ เลือกเกม ทดลอง 1 คนหรือเดโมทุก 5 วินาทีได้โดยไม่ต้องเปิดคอมเซิร์ฟเวอร์
- ตอนรับของขวัญจริง ใช้โปรแกรม Windows รุ่น 1.6.0 ขึ้นไป เปิดเกม แล้วกดสร้างลิงก์ไลฟ์
- กด «เปิดจอ Pages» หรือ «คัดลอกจอ Pages» ในโปรแกรม ลิงก์นี้เชื่อม Tunnel ให้แล้ว ใช้ใน LIVE Studio 1080 × 1920
- ถ้าใช้หน้าเว็บรวม ให้เลือกเกมเดียวกัน แล้ววางลิงก์ trycloudflare.com ในช่องเชื่อมต่อไลฟ์
- ปิด Tunnel แล้วการรับกิจกรรมสดหยุด แต่เว็บยังเปิดเดโมได้ ชื่อ/คะแนนจริงควบคุมจากคอมเท่านั้น
- ลิงก์หน้า Pages คงที่ ส่วน backend ในลิงก์หน้าจอไลฟ์ต้องใช้ Tunnel ปัจจุบันเมื่อเริ่มรอบใหม่
- เพลงและเสียงอ่านชื่อแบบ native ยังออกจากโปรแกรม Windows ใช้การจับเสียงระบบของ LIVE Studio ปิดเสียงพูดซ้ำจากหน้าเว็บถ้าใช้เสียงในโปรแกรม
- เก็บของขวัญจริง/เดโมแยกกัน เดโมไม่เพิ่มคะแนนจริง และใช้ภาพ/ตัวละคร/เพลงเดิมของเกม

## อัปเดตเว็บ

```powershell
python web/build.py
node --test web/runtime.test.mjs
wrangler pages deploy dist/pages --project-name pixpup-live-games --branch codex/three-games
```

ไม่ต้องใช้ Pages Functions หรือ Workers ที่รันตลอดเวลา ส่วนเซิร์ฟเวอร์ยังเปิดเฉพาะตอนใช้งาน

ตัว build คัดลอกเฉพาะหน้าเกม CSS JS รูป เสียง และประกาศสิทธิ์ ไม่รวม Python/Node server, gift-map, บันทึกเหตุการณ์หรือข้อมูลบัญชี และตรวจขนาดไฟล์ไม่เกิน 25 MiB

Pages ติดต่อได้เฉพาะลิงก์ HTTPS trycloudflare.com ของผู้ใช้ ตรวจชื่อเกมและ protocol ก่อนอ่าน event ส่วน gateway อนุญาต CORS ให้ origin Pages ที่ตั้งไว้เท่านั้นและไม่ส่งต่อ POST/PUT/DELETE/PATCH/OPTIONS ไปยังเกม
