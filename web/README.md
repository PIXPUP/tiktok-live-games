# Pages + Tunnel

เว็บรวม: https://pixpup-live-games.pages.dev

- เปิดเว็บ เลือกเกม ทดลอง 1 คนหรือเดโมทุก 5 วินาทีได้โดยไม่ต้องเปิดคอมเซิร์ฟเวอร์
- ตอนรับของขวัญจริง ใช้โปรแกรม Windows รุ่น 1.6.0 ขึ้นไป เปิดเกม แล้วกดสร้างลิงก์ไลฟ์
- กด «เปิดจอ Pages» หรือ «คัดลอกจอ Pages» ในโปรแกรม ลิงก์นี้เชื่อม Tunnel ให้แล้ว ใช้ใน LIVE Studio 1080 × 1920
- ถ้าใช้หน้าเว็บรวม ให้เลือกเกมเดียวกัน แล้ววางลิงก์ trycloudflare.com ในช่องเชื่อมต่อไลฟ์
- ปิด Tunnel แล้วการรับกิจกรรมสดหยุด แต่เว็บยังเปิดเดโมได้ ชื่อ/คะแนนจริงควบคุมจากคอมเท่านั้น
- ลิงก์หน้า Pages คงที่ ส่วน backend ในลิงก์หน้าจอไลฟ์ต้องใช้ Tunnel ปัจจุบันเมื่อเริ่มรอบใหม่
- เพลงและเสียงอ่านชื่อแบบ native ยังออกจากโปรแกรม Windows ใช้การจับเสียงระบบของ LIVE Studio ปิดเสียงพูดซ้ำจากหน้าเว็บถ้าใช้เสียงในโปรแกรม
- เก็บของขวัญจริง/เดโมแยกกัน เดโมไม่เพิ่มคะแนนจริง และใช้ภาพ/ตัวละคร/เพลงเดิมของเกม

## อัปเดตเว็บ

```powershell
python web/build.py
node --test web/runtime.test.mjs
wrangler pages deploy dist/pages --project-name pixpup-live-games --branch codex/three-games
```

หน้าเกมเป็นไฟล์ static ส่วนการตรวจสิทธิ์ใช้ Pages Worker เมื่อมี request เซิร์ฟเวอร์กิจกรรมยังเปิดเฉพาะตอนใช้งาน Tunnel

ตัว build คัดลอกเฉพาะหน้าเกม CSS JS รูป เสียง และประกาศสิทธิ์ ไม่รวม Python/Node server, gift-map, บันทึกเหตุการณ์หรือข้อมูลบัญชี และตรวจขนาดไฟล์ไม่เกิน 25 MiB

Pages ติดต่อได้เฉพาะลิงก์ HTTPS trycloudflare.com ของผู้ใช้ ตรวจชื่อเกมและ protocol ก่อนอ่าน event ส่วน gateway อนุญาต CORS ให้ origin Pages ที่ตั้งไว้เท่านั้นและไม่ส่งต่อ POST/PUT/DELETE/PATCH/OPTIONS ไปยังเกม

## จัดของขวัญบนเว็บ

ในหน้าเกมเปิด «จัดของขวัญและตำแหน่งแถบ» เลือกช่องกิจกรรม ค้นหาของขวัญจากคลัง 1,851 รายการ และเลือกตำแหน่ง/ขนาดได้ หน้าเว็บเก็บค่าของแต่ละเกมในเบราว์เซอร์และแนบไปกับลิงก์หน้าจอ ใช้ดาวน์โหลดการตั้งค่าเพื่อเก็บข้ามเครื่อง

รับของขวัญจริง: ในโปรแกรมรุ่น 1.7.0 เปิดเกมเดียวกัน กดนำเข้าของขวัญ / จัดหน้าจากเว็บ เลือกไฟล์ที่โหลดมา แล้วคัดลอกจอ Pages ใหม่ ไม่ต้องเปิด JSON แก้เอง โปรแกรมตรวจไฟล์กับแค็ตตาล็อกแล้วเปลี่ยนการจับคู่ผ่าน bridge ในเครื่อง หน้าเว็บแสดงว่าภาพกับการรับจริงตรงกันหรือยัง Tunnel ไม่เปิด POST/control สาธารณะ

คลังรูปเก็บที่ gift-library สามารถอัปเดตด้วย python web/download_gifts.py (ต้องมี curl) ตัวดาวน์โหลดใช้ไฟล์แค็ตตาล็อก cache ใน build/gift-sources ถ้าจะดึงรายการใหม่ให้สำรอง cache แล้วโหลดแค็ตตาล็อกใหม่ รายการใน snapshot ไม่รับประกันของทุกประเทศ/ทุกห้อง ภาพเป็นของ TikTok และเจ้าของสิทธิ์

## Firebase login (1.8.0)

ติดตั้ง dependencies ด้วย npm ci ก่อน python web/build.py ระบบ build จะ bundle Firebase Auth client กับ Pages Worker ทุกเส้นทางหน้าเกม/ข้อมูลผ่านการตรวจ Firebase ID token ผู้ใช้ต้องสมัคร/เข้าสู่ระบบก่อนใช้เว็บ ลิงก์จอไลฟ์ต้องสร้างด้วยปุ่มคัดลอกจากเว็บหลังล็อกอิน ไม่ใช้ URL หน้าจอแบบเดิมไปวางตรง ๆ ดู web/auth/README.md
