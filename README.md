## เปิดง่ายด้วยแอป Windows

ดาวน์โหลด **TikTok LIVE Game Desk** จาก [Releases](https://github.com/PIXPUP/tiktok-live-games/releases/latest) → แตก ZIP ทั้งโฟลเดอร์ → เปิด `TikTokLiveGameDesk.exe` เลือกเกม กดเปิดเกม สร้างลิงก์ Cloudflare และคัดลอกลิงก์ได้ในแอปเดียว ไม่ต้องเปิด `.bat` หรือ `.log` เอง รวม Python/Node.js/cloudflared มาแล้ว

ยังต้องติดตั้ง TikFinity และ TikTok LIVE Studio เอง ดู [วิธีใช้แอป](desktop/README.md) สำหรับรายละเอียด ปิดแอปจะหยุดเกมและลิงก์ที่แอปเปิดไว้

## ย้ายไปคอมอีกเครื่อง

1. ดาวน์โหลด repo นี้เป็น ZIP แล้วแตกไฟล์ หรือใช้ `git clone`
2. ติดตั้ง [Python 3](https://www.python.org/downloads/windows/) และ [Node.js 22 ขึ้นไป](https://nodejs.org/) ให้เรียก `python` และ `node` ได้จาก terminal เกมร้านข้าวราดแกงใช้ Node.js อย่างเดียว
3. ติดตั้ง TikTok LIVE Studio และ [TikFinity Desktop](https://tikfinity.zerody.one/) แล้วเชื่อมบัญชีที่กำลังไลฟ์ เปิด TikFinity Event API พอร์ต 21213
4. เข้าโฟลเดอร์เกมที่ต้องการ แล้วดับเบิลคลิก `START.bat` เกมจะเปิดเบราว์เซอร์และตัวเชื่อมของขวัญให้
5. ทดลองปุ่มของขวัญและเสียงจากหน้าควบคุมก่อนออกไลฟ์ ปุ่มเปิดเสียงต้องกดเองตามข้อจำกัดของเบราว์เซอร์

เปิดตัวเชื่อมของขวัญเฉพาะเกมที่กำลังใช้ หากเปิดหลายเกมพร้อมกัน ทุกเกมที่เชื่อม TikFinity อาจตอบสนองต่อของขวัญเดียวกัน การกดเดโมบางแบบเพิ่มกิจกรรมจำลอง จึงควรทดลองก่อนเริ่มรอบจริง

คะแนนและคิวอยู่ในหน่วยความจำ ไม่ได้สำรองใน GitHub การปิดเซิร์ฟเวอร์หรือรีเฟรชอาจล้างข้อมูลตามรูปแบบของแต่ละเกม

## นำภาพเข้า TikTok LIVE Studio / OBS

เพิ่ม Browser/Link Source ขนาด **1080 × 1920** แล้วใส่ URL ของเกมตามตารางพร้อม `/?overlay=1` เช่น `http://127.0.0.1:8785/?overlay=1` สำหรับคอมเครื่องเดียวกัน ถ้า LIVE Studio ไม่ยอมรับ localhost ให้ใช้ Cloudflare ตามหัวข้อถัดไป หรือจับหน้าต่างเกมแทน

เกมลานบุญ พระพิฆเนศ และตักบาตรรองรับ Cloudflare Quick Tunnel ผ่าน gateway ที่เปิดเฉพาะภาพและข้อมูลอ่านอย่างเดียว:

1. รัน `SETUP_CLOUDFLARE.bat` ที่โฟลเดอร์หลักครั้งแรก เพื่อดาวน์โหลด cloudflared จาก Cloudflare official GitHub release
2. เปิดเกมด้วย `START.bat` ก่อน แล้วเปิด `CLOUDFLARE_START.bat` ในโฟลเดอร์เกมนั้น
3. คัดลอก URL ใหม่จาก `LIVE_URL.txt` ไปใส่ LIVE Studio
4. ปิด tunnel ด้วย `CLOUDFLARE_STOP.bat` เมื่อเลิกใช้

URL ชั่วคราวอาจเปลี่ยนเมื่อเปิด tunnel ใหม่ ไม่ใช้ลิงก์จากคอมเครื่องเก่าหลังปิดเครื่องนั้น ลิงก์สาธารณะแสดงชื่อผู้ชม คะแนน และกิจกรรมได้ แต่ gateway ปิดคำสั่งแก้ไขจากภายนอกไว้ เกมร้านข้าวราดแกงรองรับลิงก์สาธารณะผ่านแอป Game Desk แล้ว สำหรับการรันด้วย START.bat แบบเดิมให้ใช้ localhost ผ่าน OBS หรือจับหน้าต่างเกม

เสียงจากหน้าควบคุมและเสียงจาก Browser Source เป็นคนละบริบท เปิดเสียงเฉพาะหน้าที่ส่งออกไลฟ์ และตรวจตัวจับเสียงใน LIVE Studio/OBS เพื่อไม่ให้ซ้ำหรือเงียบ

## แก้ไขและทดสอบ

ไม่มี npm dependencies ที่ต้องติดตั้ง Three.js ของเกมร้านข้าวราดแกงอยู่ใน `vendor` พร้อม MIT license แล้ว

รัน `TEST.ps1` จากโฟลเดอร์หลักเพื่อตรวจ JavaScript ทุกเกม, unit tests, Python gateway tests และ smoke test เซิร์ฟเวอร์ลานบุญ/พระพิฆเนศ/ตักบาตรบนพอร์ตชั่วคราว โดยไม่เพิ่มคะแนนให้รอบไลฟ์ที่เปิดอยู่
