วิธีเปิด TikTok LIVE Game Desk

1. แตก ZIP ทั้งโฟลเดอร์ก่อน ห้ามเปิด exe จากใน ZIP
2. ดับเบิลคลิก TikTokLiveGameDesk.exe
3. เลือกเกม แล้วกด เปิดเกม หน้าควบคุมจะเปิดในตัวโปรแกรมให้
4. เปิด TikFinity และเชื่อม LIVE ของบัญชีที่ใช้ไลฟ์
5. กลับมาแอป กด สร้างลิงก์ไลฟ์ แล้วกด คัดลอกลิงก์
6. นำลิงก์ไปเพิ่มเป็น Link ใน TikTok LIVE Studio ขนาด 1080 × 1920
7. เปิดและทดสอบเสียงจากหน้าที่ใช้ส่งออกไลฟ์

รุ่น 1.1.0: เดโมครั้งละ 1 คน ทุก 5 วินาที
หน้าควบคุมในโปรแกรมเลือกเสียงไทย Google หรือผู้ชาย ทดลองเสียง และเปิดพูดวนได้
เสียงพูดในโปรแกรมต้องใช้อินเทอร์เน็ต ไม่ต้องลงโมเดลหรือเสียงไทยใน Windows
ให้ LIVE Studio รับเสียงระบบ และปิดเสียงพูดจากหน้าเว็บเพื่อไม่ให้ซ้ำกัน

ไม่ต้องลง Python, Node.js หรือ Cloudflare แยก แต่ยังต้องมี TikFinity และ LIVE Studio
อย่าย้าย exe ออกจากโฟลเดอร์ _internal
เปิดแอปค้างไว้ระหว่างไลฟ์ ปิดแอปจะหยุดเกมและลิงก์ที่เปิดจากแอปนี้
เปลี่ยนเกมจะล้างคะแนน/คิวของรอบเดิม ลิงก์ Cloudflare อาจเปลี่ยนเมื่อเปิดใหม่

รุ่น 1.2.0: มีโหมดประหยัดสำหรับ RAM 4 GB เปิดอัตโนมัติบนเครื่อง RAM น้อย
มีปุ่มเปิดเพลงคลอและปรับความดังในหน้าควบคุมลานบุญ/พระพิฆเนศ
หลังเปลี่ยนโหมดประหยัด ให้คัดลอกลิงก์ใหม่ไปวางแล้วรีเฟรชแหล่งภาพ
คอมเก่าให้ลองไลฟ์720p30fps ปิดChromeหลังดูตัวอย่าง และใช้แหล่งภาพเดียว
