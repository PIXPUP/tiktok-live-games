# TikTok LIVE Game Desk

## รุ่น 1.5.2 — เปิดเพลงบนคอมเก่า

รวมคำสั่ง Windows MCI ไว้ที่เธรดเจ้าของอุปกรณ์เดียวกัน เพื่อให้การเปิด/ปิดเพลง การปรับความดังและการหยุดเสียงพูดเข้าถึงอุปกรณ์เดียวกันได้ รอยืนยันอุปกรณ์เริ่มเล่นสูงสุด 5 วินาทีต่อครั้ง ลองใหม่หนึ่งครั้ง และล้างอุปกรณ์เพลงที่ค้างก่อนเปิด ป้องกันกดซ้ำแล้วสั่งปิดเพลงตามมา หน้าควบคุมแสดงสถานะและข้อผิดพลาดจริง หากไดรเวอร์ไม่รองรับ repeat จะวนเพลงด้วยคำสั่งเริ่มใหม่ หากปรับความดังอัตโนมัติไม่ได้ยังเล่นต่อและแสดงข้อความให้ปรับจาก Windows ตรวจพบอุปกรณ์เสียงผิดพลาดติดต่อกันสามครั้งจะหยุดและให้กดเปิดใหม่ งานเสียงยังทำเบื้องหลัง ไม่ให้ Tk รออุปกรณ์

ยังไม่ได้ทดสอบบน Compaq ของผู้ใช้ และไม่สามารถแก้ไดรเวอร์หรือลำโพงที่เสียด้วยการปรับโปรแกรมนี้

## รุ่น 1.5.1 — คิวเสียงและเครื่องเก่า

เปิดอ่านชื่อแบบสั้นอัตโนมัติเมื่อเริ่มแอปในโหมดประหยัด RAM ปรับเองได้ในหน้าควบคุม รวมชื่อ/ข้อความซ้ำที่ยังรอหรือกำลังอ่านเพื่อไม่ให้คอมโบกินคิว เพิ่มคิวจริงสูงสุด 32 ข้อความและสาธุสูงสุด 8 ชื่อ หากเต็มจะแจ้งชัด ไม่ตัดชื่อเก่าออกเงียบ ๆ

สร้างหรือเล่นเสียงสะดุดจะลองซ้ำหนึ่งครั้ง ถ้าไม่สำเร็จจะเก็บข้อความให้กด «ลองอ่านชื่อที่ไม่สำเร็จ» มีสถานะคิว/ลองซ้ำ/ไม่สำเร็จ ลดการกวาดไฟล์แคชเหลือทุก 20 ครั้งหรือ 60 วินาที เก็บเสียงได้ 160 ไฟล์ เพิ่มเวลารออุปกรณ์เสียงเริ่มเล่นก่อนถือว่าจบ บทพูดวนและเดโมจะยอมให้ชื่อจริงมาก่อน

ยังต้องให้ TikFinity ส่งอีเวนต์ถึงเกมและใช้อินเทอร์เน็ตสร้างเสียง ไม่มีการรับประกันอ่านได้ทุกชื่อในกรณีแชตหนาแน่นหรือระบบเสียงขัดข้อง


## รุ่น 1.5.0 — อ่านชื่อคนพิมพ์สาธุ

เกมลานบุญรับ chat สาธุจาก TikFinity ได้ เปิดช่อง «อ่านชื่อเมื่อพิมพ์สาธุ · เกมลานบุญ» ในหน้าควบคุม ข้อความเสียงเป็น «สาธุคุณ[ชื่อ] ขออนุโมทนาบุญด้วย ขอให้มีความสุข สุขภาพแข็งแรง»

คนเดิมเว้น 30 วินาที คิวเสียงสาธุสูงสุด 4 ชื่อ ของขวัญจริงแทรกก่อนคิวแชต ไม่เพิ่มคะแนน/อันดับหรือเปลี่ยนชื่อผู้ส่งของขวัญล่าสุด ข้อความและชื่อที่อ่านส่งไปบริการเสียงที่เลือก ต้องให้ TikFinity รับแชตของไลฟ์ได้ก่อน


## รุ่น 1.4.2 — เพลงรำวงที่เลือก

เกมรำวงใช้ไฟล์ สามซ่า.mp3 ที่ผู้ใช้ส่งมา ทั้งเพลงในโปรแกรมและหน้าเว็บ ใช้เพลงเดิมครบทั้งเพลง วนซ้ำและลดเสียงตอนพูดตามเดิม


## รุ่น 1.4.1 — ปักหน้าควบคุม

หน้าควบคุมเปิดแบบอยู่ด้านบนโดยค่าเริ่มต้น และเป็นหน้าต่างแยกที่ไม่ซ่อนตามการย่อหน้าหลัก มีช่อง «ปักหน้าควบคุมไว้ด้านบน» ให้ปิดได้ เปิดหน้าจอเกมแล้วจะยกหน้าควบคุมกลับขึ้นมาเฉพาะเมื่อปักไว้ การเปิดเบราว์เซอร์ทำเบื้องหลังเพื่อไม่รอหน้าจอหลัก


## รุ่น 1.4.0 — รำวงสามช่า

เพิ่มเกมที่ 5 ฉากงานวัดยามเย็น นักเต้นชาย/หญิงแสดงชื่อผู้ส่ง ท่าเต้น 8 แบบ รำคู่ และเปิดฟลอร์ใหญ่ เพลงสามช่า 120 BPM ต้นฉบับเตรียมเป็นไฟล์ไว้ล่วงหน้า เปิดจากปุ่มเพลงในโปรแกรมได้ จัดรายการเกมเป็น 3 คอลัมน์และเลื่อนหน้าลงเพื่อใช้ปุ่มลิงก์ได้บนจอเล็ก


## รุ่น 1.3.3 — ไอคอนของขวัญโหลดพร้อมแถบ

รวมเฉพาะไอคอนของขวัญ WebP ขนาดเล็กเดิมลงใน CSS ของทั้งสี่เกม ลดการโหลดแยก 9 ไฟล์และโอกาสที่บางไอคอนหายเมื่อเครือข่ายสะดุด ภาพตัวละครและเสียงสวดยังคงแยกโหลดตามเดิม ไม่ได้สร้างรูปของขวัญใหม่


## รุ่น 1.3.2 — ลดงานที่ทำให้หน้าต่างค้าง

- งานเปิดเพลง หยุดเสียง และเรียกเสียงจากหน้าควบคุมทำบน worker แยกจาก Tk
- หยุดเดโมไม่รอ HTTP บนหน้าจอหลัก เลื่อนความดังเพลงไม่รอระบบเสียง
- ไม่สั่งวาดปุ่มและสถานะเดิมซ้ำ จำกัดข้อความที่ประมวลผลในแต่ละรอบหน้าจอ
- เตรียมไฟล์เฉพาะเกมที่เลือกในครั้งแรก แทนคัดลอกครบสี่เกม
- เกม 2D ไม่สร้างอันดับ/รายการกิจกรรมใหม่เมื่อ poll ได้ข้อมูลเดิม ลดเงาและเอฟเฟกต์ย่อยในโหมดประหยัด
- ยังไม่ได้วัดกับคอมเครื่องที่มีอาการ จึงไม่รับประกันว่า Not Responding จาก RAM เต็มหรือ LIVE Studio จะหาย

## รุ่น 1.3.1 — อ่านชื่อเดโม

ติ๊ก «อ่านชื่อของขวัญ / เดโม» เพื่อทดลองอ่านชื่อพร้อมกิจกรรม เดโมพูดเฉพาะเมื่อเสียงว่าง ไม่สะสมคิว และเสียงผู้ส่งจริงหยุดเดโมเพื่ออ่านชื่อจริงก่อน เดโมไม่เพิ่มคะแนนหรือเปลี่ยนชื่อผู้ส่งจริงล่าสุด


## รุ่น 1.3.0 — เพิ่มเกมตักบาตรยามเช้า

- เกมที่ 4 ฉากหน้าวัดยามเช้า พระถือบาตรรับอาหารจากผู้ส่ง
- ถวายข้าว กับข้าว ผลไม้ น้ำดื่ม ขนม เครื่องดื่ม และชุดอาหาร
- หน้าควบคุมในโปรแกรมมีเพลงคลอ เดโม 5 วินาที และบทขอบคุณสำหรับตักบาตร
- รองรับ Cloudflare, TikFinity และโหมดประหยัด RAM เช่นเดียวกับเกมเดิม

## รุ่น 1.2.1 — เปิดเดโมพร้อมของขวัญจริง

- เปิดเดโมค้างได้ ของขวัญจริงแทรกเข้ามาพร้อมชื่อผู้ส่ง
- เกมลานบุญ/พระพิฆเนศให้ผู้ส่งจริงแทนที่ตัวละครเดโมก่อน เดโมไม่ไล่ชื่อผู้ส่งจริงออกจากจอ
- เดโมไม่เพิ่มคะแนน/อันดับจริง และไม่แทรกเสียงขอบคุณผู้ส่งจริง
- ร้านอาหารแทรกคิวจริงก่อนคิวเดโมที่ยังรออยู่ โดยเสิร์ฟคนที่กำลังสั่งให้เสร็จก่อน
- หน้าควบคุมแสดงชื่อผู้ส่งจริงล่าสุดแม้ไม่ได้เปิดเสียง

## รุ่น 1.2.0 — คอม RAM น้อยและเพลงในโปรแกรม

- เปิดโหมดประหยัดอัตโนมัติเมื่อพบ RAM ต่ำกว่า 6 GB และเลือกเปิด/ปิดเองได้
- โหมดประหยัดลดเอฟเฟกต์เกมทำบุญ จำกัดคนที่แสดงพร้อมกัน 4 คน (ยังนับของขวัญ/คะแนนครบ) และลดจำนวนตัวละครภาพเมื่อรับคอมโบ
- เกมร้านข้าวราดแกงจำกัด 30 FPS ปิดเงา 3D/antialias และลดความละเอียดภายในเป็น pixel ratio 1 เฉพาะโหมดประหยัด
- แยกภาพและเสียงออกจากโค้ดแบบ content-addressed assets เพื่อโหลดเมื่อใช้งานและ cache ได้ ไม่โหลดเสียงสวดก้อนใหญ่ไว้ใน JavaScript ตั้งแต่เริ่ม
- JS+CSS ของลานบุญลดจาก 6,926,349 เหลือ 101,766 ไบต์ และพระพิฆเนศจาก 6,469,139 เหลือ 104,826 ไบต์ (ตัวเลขก่อนเติมโหมดประหยัดเพิ่มเล็กน้อย) ตัวไฟล์ภาพ/เสียงยังคงอยู่และต้องโหลดเมื่อใช้ ตัวเลขนี้ไม่ใช่ผลวัด RAM รวม
- หน้าควบคุมลานบุญ/พระพิฆเนศมีปุ่มเปิด–ปิดเพลงคลอและความดัง เพลงต้นฉบับสร้างเป็นไฟล์ WAV เล็กไว้ล่วงหน้า วนจากโปรแกรมและลดความดังตอนพูด ไม่ต้องเปิด Chrome เพื่อเล่นเพลง
- ถ้าเปิด/ปิดโหมดประหยัดขณะมีลิงก์ ให้คัดลอกลิงก์ใหม่ไปแทนใน LIVE Studio แล้วรีเฟรชแหล่งภาพ

### ตั้งค่าที่เหมาะสำหรับทดลองบนคอม RAM 4 GB

เริ่มไลฟ์ที่ 720p / 30 FPS ปิด Chrome หลังดูตัวอย่าง ใช้เกมและ Link Source เพียงหนึ่งจอ ปิดแหล่งภาพ/โปรแกรมอื่นที่ไม่ใช้ และใช้ตัวเข้ารหัสฮาร์ดแวร์หากเครื่องมีให้เลือก

ยังไม่รับประกันความลื่นบน RAM 4 GB เพราะ TikFinity, LIVE Studio, Windows และการ์ดจอแบบใช้ RAM ร่วมกันอยู่นอกการควบคุมของแอป ถ้ายังหน่วงให้ลดความละเอียดอีกหรือเพิ่ม RAM เมื่อทำได้

## รุ่น 1.1.0

- เปิดเกมแล้วเปิด **หน้าควบคุมในโปรแกรม** อัตโนมัติ ไม่ต้องใช้ Chrome สำหรับปุ่มของขวัญ เดโม และเสียงพูด
- เดโมครั้งละ 1 คน ทุก 5 วินาที ทั้งในแอปและหน้าเว็บ
- เลือกเสียงไทย Google (ค่าเริ่มต้น) หรือเสียงผู้ชายนิวัฒน์ กดทดลองเสียง กล่าวขอบคุณผู้ส่งของขวัญ และแก้ไข/เปิดพูดวนบทอวยพรได้
- เสียงใหม่สร้างผ่าน Google Translate TTS (gTTS) หรือ Microsoft Edge (edge-tts) ไม่ต้องลงโมเดลหรือเสียงไทยใน Windows ไม่ต้องใส่ API key แต่ต้องใช้อินเทอร์เน็ต บริการภายนอกอาจเปลี่ยนแปลงหรือขัดข้องได้
- เปิดเสียงจากหน้าควบคุมในโปรแกรม แล้วให้ LIVE Studio จับ **เสียงระบบ** ปิดเสียงพูดจากหน้าเว็บเพื่อไม่ให้ซ้อนกัน ข้อความและชื่อที่อ่านจะถูกส่งไปยังบริการเสียงออนไลน์เมื่อผู้ใช้เปิดใช้เสียง
- หน้าจอเกมสำหรับ LIVE และการตั้งค่าเว็บเพิ่มเติมยังเปิดแยกได้จากปุ่มในแอป ส่วนเสียงสวดยังคงตั้งค่าได้จากหน้าเว็บเพิ่มเติม และรุ่น 1.2.0 มีเพลงคลอในโปรแกรมแล้ว
- เก็บการจับคู่ของขวัญเดิมจากรุ่นก่อนเมื่อย้ายมาใช้ 1.1.0

แอป Windows รวมทั้งสี่เกม เปิด–ปิดเกม หน้าควบคุม หน้าจอไลฟ์ สร้าง/ปิดลิงก์ Cloudflare และคัดลอกลิงก์ในหน้าเดียว ตัวแอปเปิดเกมได้ครั้งละหนึ่งเกมเพื่อไม่ให้ของขวัญซ้ำหลายเกม

## สำหรับผู้ใช้

1. ดาวน์โหลด ZIP จากหน้า Releases แล้ว **แตกไฟล์ทั้งโฟลเดอร์**
2. ดับเบิลคลิก `TikTokLiveGameDesk.exe` ที่อยู่ด้านนอกโฟลเดอร์ `_internal` อย่าย้าย exe แยกจาก `_internal`
3. เลือกเกม → เปิดเกม → เปิด TikFinity และเชื่อม LIVE
4. กดสร้างลิงก์ไลฟ์ → คัดลอกลิงก์ ไปวางใน TikTok LIVE Studio ขนาด 1080 × 1920
5. เปิดเสียงที่หน้าควบคุม/แหล่งภาพที่ใช้ส่งเสียงจริง ตรวจเสียงก่อนเริ่ม

รวม Python, Node.js และ cloudflared แล้ว ไม่ต้องติดตั้งแยก ไม่ต้องเปิดไฟล์ bat หรือ log เอง แต่ TikFinity และ TikTok LIVE Studio เป็นโปรแกรมแยกที่ผู้ใช้ต้องติดตั้งและเข้าสู่ระบบ

ปิดลิงก์อย่างเดียว เกมยังทำงานต่อได้ ปิดเกมหรือเปลี่ยนเกมจะล้างคะแนน/คิวในหน่วยความจำ ปิดแอปจะหยุดเกมและลิงก์ที่แอปเปิดไว้ แอปไม่ปิดโปรแกรมของผู้อื่น ถ้าเปิดเกมด้วยวิธีเก่าอยู่ ให้ปิดก่อนใช้แอป

หน้าต่างแสดงสถานะรอ TikFinity หมายถึงยังรอการเชื่อมต่อโปรแกรม ไม่ได้หมายความว่าเกมเสีย แม้สถานะเชื่อม TikFinity แล้ว ยังต้องตรวจว่า TikFinity เชื่อม LIVE บัญชีที่ถูกต้อง

ใช้ Cloudflare Quick Tunnel แบบชั่วคราว: URL อาจเปลี่ยนและไม่มีการรับประกัน uptime ผู้มีลิงก์ดูชื่อ/คะแนนได้ แต่ gateway ปิดคำสั่งเขียนและหน้าควบคุมภายในไว้ ไม่มี API เพิ่มคะแนนสาธารณะ

ข้อมูลทำงานอยู่ใน `%LOCALAPPDATA%\TikTokLiveGameDesk` ไฟล์วินิจฉัยจัดการอัตโนมัติ ปุ่มคัดลอกข้อมูลช่วยเหลือใช้เมื่อต้องการแจ้งปัญหา ข้อมูลที่คัดลอกอาจมีลิงก์สาธารณะหรือชื่อผู้เล่นจากข้อความผิดพลาด จึงควรตรวจข้อความก่อนส่งต่อ

## พัฒนาและ build

รันซอร์สด้วย `python desktop/app.py` (ต้องมี Node.js และ cloudflared ใน PATH หรือใน runtime) ทดสอบด้วย `python -m unittest discover -s desktop -p 'test_*.py'` และ `node --test desktop/curry-poll.test.mjs`

build บน Windows x64 ด้วย Python 3 และ Node.js:

```powershell
python -m pip install --target .build-tools pyinstaller==6.22.3 edge-tts==7.3.1 gTTS==2.5.4
./desktop/BUILD.ps1
```

ผลลัพธ์อยู่ใน `dist/TikTokLiveGameDesk-v1.5.1-Windows-x64.zip` โค้ดดูแลกระบวนการใช้ Windows Job Object เพื่อเก็บกวาดเกมและ tunnel หากแอปถูกปิดกะทันหัน บันเดิลเป็นแบบโฟลเดอร์เพื่อลดเวลาเปิดและไม่แตกไฟล์ขนาดใหญ่ทุกครั้ง
